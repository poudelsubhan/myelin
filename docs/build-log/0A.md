# 0A — Scaffold, executable contracts, CRM and probes

Started 2026-09-08 in a planning-only directory. No existing application or Git
history was overwritten. Implemented strict Pydantic persistence contracts and
runtime protocols with explicit unavailable providers before engine consumers.
Locked the independent CRM oracle specification and eight varied inputs.

SQLite write and operation-result records share one transaction. Operation
lookup is tenant-scoped and waits on active transactions; same-ID conflicting
business payload fails. Token-source GETs rotate session-bound CSRF. Mutation
reset requires its exact revision, preventing validation on accidentally clean
apps. The consent modal is explicitly UI-only, so HTTP resilience is not falsely
reported as a repair.

Validation: `uv run pytest -q` — 19 passed; `uv run ruff check .` — passed.
Tests cover authentication, CSRF freshness, pre-write value rejection, retry
identity, duplicate-payment prevention, status reconciliation, tenant isolation,
mutation resets and contract JSON round-trips/hash sensitivity.

Development fix: canonical date comparison was added alongside parsing so a
compact YYYYMMDD string cannot silently bypass the stated ISO-date contract.
The invalid date tests exercise this behavior.
