# 6B — Hosted analysis and staged candidate patches

The compiler provider uploads a sanitized trace/network JSON bundle to an actual
hosted container with networking disabled. Astra reads it with hosted shell,
correlates requests and dependencies, then reuses the same container for a second
analysis response. Myelin consumes hosted outputs and never executes them locally.

Only program.json and source-map.json are patchable in a fresh staging directory.
V4A create/update/delete results retain their original call IDs. Traversal,
symlinks, oversized files, malformed diffs, invalid schemas and a final program
that differs from the staged bytes cannot enter the adoption path. A completed
patch still requires independent validation and a parent/hash comparison.
