# 1C — Orchestrator and live console

2026-09-08. CLI submits jobs to the single port-8100 server, which owns sessions,
recording and execution. Append-first JSONL events have monotonic per-run sequence
IDs; separate subscriber queues support fan-out and replay. The console renders
actual action events, frames, response usage and oracle results using textContent.

Tests cover two concurrent subscribers, restart/replay sequences, fixture service
injection and explicit unavailable modes. Both Phase 1 live run IDs in 1A/1B are
server-created and their timelines are available in the console.
