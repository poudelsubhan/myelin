# 5B — Typed branches

The interpreter evaluates typed predicates, queues only selected children and
executes a common suffix once. Nested IDs remain globally unique. A path-sensitive
validator intersects variable/secret/dependency definitions at a branch join;
references available on only one side are rejected. A branch leaves the last
actual I/O kind intact, preserving HTTP-to-UI resume requirements.

Tests execute lower/equal/upper boundary paths, reject mixed operand types and
missing definitions, and check nested IDs. Real expense runs exercise the bearer
bridge on both paths. Gate coverage is assembled from execution artifacts and
lists true, false and equality case IDs; missing branch outcomes cannot pass.
